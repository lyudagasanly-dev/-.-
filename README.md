# Проект автоматизации тестирования интернет-магазина «Читай-город»

Дипломный проект по автоматизации UI и API тестирования с использованием современных инструментов и паттернов проектирования.

## 🚀 Используемые технологии и условия среды
* **Язык программирования:** Python 3
* **Тестовый фреймворк:** PyTest
* **UI Автоматизация:** Playwright (Python)
* **Архитектурный паттерн:** Page Object Model (POM)
* **Отчетность:** Allure Framework
* **Стандарты форматирования:** PEP 8 (Flake8)

## 📦 Архитектура проекта
* `pages/` — компоненты страниц (Page Object). Содержит базовые методы взаимодействия с элементами и локаторы интерфейса.
* `tests/` — UI и API тест-кейсы.
* `conftest.py` — конфигурационные фикстуры, включая механизмы перехвата сетевых запросов (`ui_page.route`) для изолированного тестирования фронтенда.
* `config.py` — конфигурационные файлы тестового окружения.

## 🛠 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd diploma_project
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Установите браузерные бинарники Playwright:**
   ```bash
   playwright install
   ```

4. **Запуск тестов с генерацией логов Allure:**
   ```bash
   pytest -v --alluredir=allure-results
   ```

5. **Просмотр отчета Allure в браузере:**
   ```bash
   allure serve allure-results
   ```
